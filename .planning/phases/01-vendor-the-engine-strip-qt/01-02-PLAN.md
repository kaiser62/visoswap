Add `tests/test_no_qt_source.py` with `test_no_qt_source_references`, a static scan over every
`.py` file under `visoswap/`. Read each file with the `tokenize` module and drop every `COMMENT`
token before matching. Do **not** use a line-oriented filter: upstream code has trailing inline
comments, and a `grep -v '^#'` style filter keeps them, so a removal note written at the end of a
code line would either trip the gate or — worse, if the filter over-matches — mask a real
reference. Token-level stripping is exact.

symbol names, and for any `app.ui` reference. Fail with file and line number for each hit. Apply
the same `PENDING_QT_STRIP` exclusion, keyed on file path, so this test and the import gate go
green together in plan 04.

Both tests must be dependency-free — the static scan reads source and never imports, so it runs on
any interpreter including the repo's default 3.13.
