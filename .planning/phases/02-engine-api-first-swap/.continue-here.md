## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| False requirement completion | The SDK trusts plan frontmatter, which names the requirement a *phase* serves. Marking it per-plan silently corrupts the traceability table, and every later audit believes it. | blocking | Defer ENGINE-01 to 02-04, after a real swap. Re-grep `REQUIREMENTS.md` after each state update. |
| Trusting `<measured_facts>` without re-measuring the edge | 02-01's plan recorded four widget shapes and 94 int keys. There are five and 93 — `ClipText` carries min/max with **no** `step`. The stated rule does not mistype it, it crashes on `int(float(''))`. | advisory | Phase 3 regenerates this same data as a real schema. Reuse `tools/dump_engine_settings.py::shape_of`, which is correct, rather than re-deriving from the plan text. |
| Reading `find "D:/Visomaster" -newermt '-1 day'` as damage you caused | 21 paths under `D:/Visomaster/tensorrt-engines/` carry mtimes from 00:19–00:32 on 2026-08-21, before this session. Pre-existing TensorRT cache. The plan's verification step 5 says this must print nothing; it does not, and never will. | advisory | Use `find "D:/Visomaster" -newer <a file stamped at plan start> -not -path '*/dependencies/*'`. That prints nothing and is the assertion that actually concerns your plan. |
| Assuming the engine interpreter can import `tests/conftest.py` | It imports pytest at module scope, and pytest is installed on **neither** engine interpreter. Anything a subprocess needs must come from `tests/_blocked_roots.py` (which imports nothing) or from argv. | advisory | Put shared constants in `_blocked_roots.py`; `conftest.py` re-exports them for the pytest side. |
| Running engine code from the wrong working directory | `models_dir` is the relative string `./model_assets` until Phase 4, and TensorRT's provider options write a cache to a relative `tensorrt-engines/`. The nested `tensorrt-engines/tensorrt-engines/` in the source tree is what that mistake looks like. | advisory | Drive the runner through `tests/conftest.py::run_engine_runner`, which already sets `cwd` to the repository root. |
