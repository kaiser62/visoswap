# BLOCKING CONSTRAINTS — Read Before Anything Else

> These are not suggestions. Each constraint below was discovered through failure.
> Acknowledge each one explicitly before proceeding.

- [ ] CONSTRAINT: **Backend settings wiring name-collision** — in `backend/main.py`, the top-level `from backend.api import settings` module is shadowed inside `create_app()` by the existing local `settings = get_settings()` (a pydantic `Settings` instance). So `app.include_router(settings.router)` resolves to a Settings object and raises `AttributeError: 'Settings' object has no attribute 'router'`. Fix by **aliasing the module import** (`from backend.api import settings as settings_api`, call `settings_api.router`); keep the `settings = get_settings()` local as-is. This is the immediate blocker before any Phase 5 backend test can collect.

**Do not proceed until all boxes are checked.**
