Schema entry shape (visoswap/schema/schema.json — the single source the UI renders from):
```ts
type SettingsType = 'toggle' | 'int' | 'float' | 'selection' | 'text'
interface SchemaGate {
  mechanism: 'toggle' | 'selection'
  parents: string[]
  required_value: boolean | string
  rule: 'single' | 'all' | 'last'
}
interface SchemaEntry {
  type: SettingsType
  tier: 'global' | 'project'
  group: string          // 21 distinct logical groups, e.g. 'Face Mask', 'Swapper', 'Export'; ~42 keys carry an EMPTY '' group (face_editor sub-controls) — fall back to the label 'Other' for empty group strings so the sidebar never renders an unnamed section
  label: string
  help?: string
  level?: number         // 1 | 2 — nesting depth, informational
  default?: unknown      // null only for the dynamic DFM key
  minimum?: number
  maximum?: number
  step?: number          // ints/floats; absent means default increments (ClipText has min/max-like fields? no — text entries carry max_length/min_length instead)
  decimals?: number      // float entries, e.g. 2
  options?: string[] | null  // null = dynamic (DFMModelSelection); GET /api/schema resolves it to a list
  options_from?: string | null
  gate?: SchemaGate | null
  max_length?: number    // text entries (ClipText: 1000)
  min_length?: number
}
type SettingValue = boolean | number | string
type Values = Record<string, SettingValue>
```

The two pathological keys the fidelity tests must pin (from CONTEXT.md, D-03 rationale):
- ClipText: type text, max_length 1000, min_length 0, default "" — must render a text input, never a slider or a numeric parse
- VideoPlaybackCustomFpsSlider: type int, min 1 max 120 step 1 — must render an int slider
- ColorBrightnessDecimalSlider: type float, min 0 max 2 step 0.01, decimals 2 — must render a float slider
- WebCamMaxFPSSelection: type selection with STRING options ["23","30","60"] — values stay strings
- DFMModelSelection: type selection, options null in the committed schema — renders a disabled select with an unavailable hint when the list is empty

UI-SPEC design tokens to apply (approved contract): spacing multiples of 4; body 14/400, label 14/600, heading 16/600, display 20/600; accent #2563EB (blue-600) reserved for active sidebar item + focus rings + dirty markers + primary button; destructive #DC2626 (red-600) for discard/reset; neutrals neutral-50 page bg / white cards / neutral-200 borders / neutral-500 secondary text; control heights h-8.
