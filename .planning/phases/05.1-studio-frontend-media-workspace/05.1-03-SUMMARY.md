## Decisions Made
- Preview reports `round(int(t*fps)/fps, 3)` — the identical floor `EngineFrameGenerator.generate_at` applies, so preview and overlay agree on which frame a time means.
- Local time in `_stem` preserved deliberately (predecessor semantics): the name is read by the person at the machine, not by a program.
- Takes names must survive `sanitize_filename` unchanged. Consequence accepted: `_free_path`'s `" (N)"` collision numbering produces names the API lists but won't serve/delete (space+parens don't survive the sanitize round-trip). Same-second collisions are rare (stamps separate runs by design); renaming manually recovers them. Softening this would mean serving names the sanitizer wouldn't produce — rejected.
- Slash-bearing traversal (`../app.db`, `..%2Fapp.db`) is structurally undeliverable as a `{name}` param on any ASGI stack — clients normalize or servers decode `%2F` before route matching. Those shapes are refused by routing itself (404), one gate earlier than the validator's 400; backslash and drive-relative shapes reach the validator and get 400. Both arms are tested where they actually live.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking criterion] Four traversal tests adjusted to deliverable wire shapes**
- **Found during:** Task 3 (RED/GREEN boundary)
- **Issue:** Raw `../app.db` is normalized client-side by httpx (as by browsers) and `%2F…` decodes into a real slash before Starlette matches `{name}` ([^/]+) — both verified by probes — so those exact wire forms can never reach the handler to answer 400 on any server.
- **Fix:** Kept four separate traversal tests mapped to what actually arrives: backslash multi-dotdot (400 at validator), `%2F` multi-dotdot (404 at routing — asserted with the reason inline), `D:\elsewhere\app.db` absolute-backslash (400), plain backslash name (400). The security claim ("no string reaches the filesystem unvalidated") is asserted at the layer that receives each shape.
- **Files modified:** tests/test_api_takes.py
- **Verification:** suite green; containment holds on every arm
- **Committed in:** c283d58
