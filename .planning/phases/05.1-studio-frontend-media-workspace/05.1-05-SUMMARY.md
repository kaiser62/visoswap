# Phase 05.1 Plan 05: Live overlay — media state, the informational socket, and a non-stalling player Summary

**Generated frames now appear over the playing video through a positioned-image overlay driven by an in-memory frame index, a reducer-owned media container, and a socket that refetches instead of trusting itself.**

## Performance

- **Duration:** ~35 min across the original run and this continuation
- **Tasks:** 3
- **Files modified:** 12 (9 created, 3 modified)

## Accomplishments
- `frameindex.ts`: React-free hot path with a binary-search `frameAtOrBefore` that returns null rather than a future frame (D-15d), plus sorted `upsert`.
- `ws.ts`: typed project socket with heartbeat drop, guarded parsing, bounded exponential backoff, and a refetch callback on every open — the backend hub drops events for a saturated subscriber, so the index is the only truth.
- `MediaContext.tsx`: one `useReducer` owning the run, the index, the socket state, the failed tally, the range marks and the mode; reconnect replaces the index wholesale rather than merging.
- `PlayerCard.tsx` + `Transport.tsx`: overlay image swapped from the local index on `timeupdate` with zero frame-at requests, throttled advisory position reporting (immediate + `seeked` on a seek), image-error degradation to the raw video, and mark/seek controls.
- `PlayerCard` replaces plan 04's left-column placeholder; the 201-control DOM gate and shell tests still pass.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] The media-context bootstrap test never simulated the socket opening**
- **Found during:** Task 2 (continuation — the interrupted run left this test failing)
- **Issue:** `bootstrapped()` asserted two `/frames` fetches (bootstrap + refetch-on-open) but the fake socket only opens when the test calls `serverOpen()`, which it never did. Real sockets open themselves; the fake does not.
- **Fix:** `bootstrapped()` now dispatches `serverOpen()` on the created socket before the final flush. The assertion is unchanged, so the refetch-on-open contract is still what is being proven.
- **Files modified:** `frontend/src/test/media-context.test.tsx`
- **Verification:** `npm --prefix frontend test` — 66/66 pass.
- **Committed in:** `92670af`

**2. [Rule 3 - Blocking] Unused binding failed the typecheck**
- **Found during:** Task 2
- **Issue:** `tsc -b` failed with `TS6133: 'fetchMock' is declared but its value is never read` in the reconnect test, blocking the build gate.
- **Fix:** Call `installFetch()` for its side effect without binding it.
- **Files modified:** `frontend/src/test/media-context.test.tsx`
- **Committed in:** `92670af`

**3. [Rule 1 - Bug] Media listeners were never attached**
- **Found during:** Task 3
- **Issue:** The `timeupdate`/`seeked` effect ran once at mount, when the video element does not yet exist (it renders only after the project payload arrives), and never re-ran — so the overlay never swapped and no position was ever reported.
- **Fix:** Keyed the effect on `project?.video_src` as well as the report callback.
- **Verification:** `player-overlay.test.tsx` 11/11 pass.
- **Committed in:** `e312682`
